# stratego-lite —— 简化版陆军棋

原创小项目：把经典陆军棋（Stratego）压缩到 6x6 棋盘、每方 12 枚棋子，
保留隐藏军衔、交战结算、侦察兵长走、间谍刺杀元帅、夺旗获胜等核心乐趣。
纯 Python 标准库，无第三方依赖。

## 玩法

- 6x6 棋盘，中央 2x2 湖泊不可进入；每方 12 枚棋子随机布于己方底线两行。
- 棋子：1 元帅、2 将军、3 上校、4 上尉×2、5 中尉×2、6 少尉、
  9 侦察兵（直线走任意格，不可跳子）、S 间谍、B 炸弹、F 军旗。
- 军衔对敌方隐藏（显示 `?`），交战后双方公开参战棋子。
- 每次沿横/竖走一格；炸弹与军旗不可移动。
- 交战：数字小者胜（1 最强），同级同归于尽；
  间谍**主动进攻**元帅时获胜，其余情况间谍必败；
  进攻炸弹者阵亡；夺取军旗直接获胜。
- 对方无可走棋子时亦判负；400 半回合未分胜负判和棋。

## 用法

```bash
python -m stratego_lite                 # 人机对战（你是红方）
python -m stratego_lite --auto --games 10 --seed 42
python -m stratego_lite --auto --games 5 --verbose   # 看每步战报
```

走法输入如 `b2 b3`，`q` 退出。

## AI

1 步贪心：优先夺旗；对已公开敌子按交战结果估值（吃子加分、送死扣分）；
对未公开敌子用平均价值估算，侦察兵试探有加成；附带向敌方底线推进与随机扰动。
AI 很弱——只看一步，不懂布阵、佯攻与残局规划，熟悉规则的人类通常能赢。

## 已知局限（诚实版）

- **简化规则**：无工兵（炸弹不可拆除，见子就炸）、无布雷以外的开局布阵策略、
  无原版 10x10 / 40 子的大棋盘，不可当标准陆军棋用。
- AI 只是 1 步贪心，不做深层搜索。
- 文本棋盘，无图形界面/存档/悔棋/网络对战；Python 3.10+。
